مدیریت حرفه‌ای قطعه کدهای HTML/CSS/JS/PHP با شورت‌کد، شرط‌های نمایش پیشرفته، بلوک گوتنبرگ و حالت ایمن.

== Description ==

این افزونه به شما اجازه می‌دهد قطعه کدهای HTML، CSS، JavaScript و PHP بسازید و آن‌ها را به‌صورت کنترل‌شده در سایت نمایش دهید — بدون دست‌زدن به فایل‌های قالب و بدون خطر تداخل با افزونه‌های دیگر.

= قابلیت‌های اصلی =

* **ادیتور کد حرفه‌ای** با CodeMirror و رنگ‌آمیزی نحوی برای شش فیلد مجزا (PHP، هدر، HTML، CSS، JS، فوتر)
* **شورت‌کد اختصاصی** برای هر قطعه کد: `[my_snippet id="123"]`
* **بلوک گوتنبرگ** با انتخابگر کشویی — بدون نیاز به تایپ شورت‌کد
* **شرط‌های نمایش پیشرفته**: نوع محتوا، دسته/برچسب، قالب صفحه، نقش کاربر، وضعیت ورود، دستگاه، بازه زمانی، پارامتر URL و کوکی
* **بارگذاری تنبل**: اجرای کد پس از اولین تعامل کاربر یا هنگام ورود به دید (IntersectionObserver)
* **تحویل فایلی CSS/JS** برای بهره‌مندی از کش مرورگر و بهبود سرعت
* **درون‌ریزی و برون‌بری JSON** برای انتقال بین محیط توسعه و تولید
* **حالت ایمن**: اگر قطعه کدی خطای مرگبار بدهد، خودکار غیرفعال می‌شود و سایت سفید نمی‌شود
* **لاگ حسابرسی**: چه کسی، چه زمانی، چه چیزی را تغییر داد
* **بازنگری کدها**: نسخه‌بندی و بازگردانی کدها
* **جایگزینی محتوای صفحه** با پشتیبانی ویژه از صفحه محصول ووکامرس

= امنیت =

این افزونه با رویکرد «امن به‌صورت پیش‌فرض» ساخته شده است:

* اجرای کد PHP به‌صورت پیش‌فرض **غیرفعال** است
* کدهای PHP با امضای رمزنگاری‌شده HMAC-SHA256 محافظت می‌شوند — دستکاری مستقیم دیتابیس بی‌اثر است
* ذخیره HTML/JS خام نیازمند دسترسی `unfiltered_html` است
* همه درخواست‌های AJAX دارای بررسی nonce و سطح دسترسی هستند
* کدها از REST API افشا نمی‌شوند

== Installation ==

1. پوشه افزونه را در `/wp-content/plugins/` قرار دهید یا فایل ZIP را از پیشخوان بارگذاری کنید.
2. افزونه را از منوی «افزونه‌ها» فعال کنید.
3. از منوی «قطعه کدهای من» اولین قطعه کد خود را بسازید.

= فعال‌سازی اجرای PHP (اختیاری و پرخطر) =

به‌صورت پیش‌فرض اجرای PHP غیرفعال است. اگر واقعاً به آن نیاز دارید، این خط را به `wp-config.php` اضافه کنید:

`define( 'CHS_DISABLE_PHP', false );`

سپس هر قطعه کد PHP را یک‌بار باز و ذخیره کنید تا امضای امنیتی ساخته شود.

== Frequently Asked Questions ==

= چرا کد PHP من اجرا نمی‌شود؟ =

سه دلیل ممکن است:

1. ثابت `CHS_DISABLE_PHP` روی `true` است (پیش‌فرض).
2. کد امضا نشده — قطعه کد را باز و دوباره ذخیره کنید.
3. نویسنده‌ای که کد را ذخیره کرده دسترسی `unfiltered_html` ندارد.

= چطور دسترسی مدیریت قطعه کدها را به نقش دیگری بدهم؟ =

از فیلتر زیر استفاده کنید:

`add_filter( 'chs_manage_capability', function () { return 'edit_pages'; } );`

= آیا با ووکامرس سازگار است؟ =

بله. در صفحه تکی محصول، اگر گزینه «جایگزینی محتوای صفحه» فعال باشد، تمام اجزای پیش‌فرض محصول (گالری، عنوان، قیمت، دکمه خرید، تب‌ها) مخفی می‌شوند.

= اگر کد اشتباهی بنویسم سایتم از کار می‌افتد؟ =

خیر. حالت ایمن فعال است: اگر کدی باعث خطای مرگبار شود، در بارگذاری بعدی به‌صورت خودکار غیرفعال شده و اطلاع‌رسانی می‌شود. همچنین پیش از ذخیره، نگارش کد بررسی می‌شود.

= داده‌ها پس از حذف افزونه پاک می‌شوند؟ =

بله، `uninstall.php` تمام قطعه کدها، متاها، ترنزینت‌ها و فایل‌های تولیدی را پاک می‌کند. برای جلوگیری از این کار:

`define( 'CHS_KEEP_DATA_ON_UNINSTALL', true );`

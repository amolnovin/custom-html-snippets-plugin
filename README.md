# افزونه قطعه کدهای سفارشی (HTML/CSS/JS)

مدیریت قطعه‌کدهای HTML، CSS، JavaScript و PHP در وردپرس — **نسخه ۳.۰.۳**.

نویسنده: **AMOLNOVIN.IR** · مجوز: **GPL-2.0-or-later**

## نصب

فایل آماده نصب: [custom-html-snippets-3.0.3.zip](packages/custom-html-snippets-3.0.3.zip)

در پیشخوان وردپرس به «افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه» بروید و ZIP بالا را بارگذاری کنید. برای ارتقا، فایل‌های نسخه قبلی را جایگزین کنید؛ قبل از ارتقا از دیتابیس پشتیبان بگیرید و روی staging آزمایش کنید.

**ZIP خودکار Source code گیت‌هاب، بسته نصب وردپرس نیست.** فایل داخل `packages/` را نصب کنید.

حداقل نسخه‌های اعلام‌شده: WordPress 5.8 و PHP 7.4. نمونه تنظیم اجرای آزمون روی این نسخه‌ها در docs/ci/github-actions.yml.example قرار دارد؛ گردش‌کار GitHub Actions فعلاً فعال نیست.

## استفاده

```text
[my_snippet id="123"]
```

شناسه را با شناسه قطعه‌کد خود جایگزین کنید. تنظیمات نمایش شرطی، محدوده هدر/فوتر، تزریق خودکار و درون‌ریزی/برون‌بری در پیشخوان افزونه قرار دارند.

## امنیت، سئو و قابلیت‌های ۳.۰.۳

- **دسترسی سریع به ویرایش:** اگر کاربری با دسترسی مدیریت وارد شده باشد، در بالای محل نمایش قطعه‌کد در فرانت‌اند (نوشته، برگه، محصول ووکامرس و...) یک نوار اختصاصی با مشخصات قطعه‌کد و دکمه مستقیم «ویرایش قطعه‌کد» نمایش داده می‌شود. برای کاربران عادی و ربات‌ها چیزی نمایش داده نمی‌شود.
- **بهبود نمایش و اسکرول در حالت ایزوله (iframe):** نوار اسکرول ناخواسته حذف شده، ارتفاع با `ResizeObserver`، `MutationObserver` و لود تصاویر به‌صورت خودکار و دقیق تنظیم می‌شود (`overflow: hidden` و `scrolling="no"`).
- **اصلاح لینک‌های لنگر (Anchor Links) و ناوبری در iframe:** تگ پیش‌فرض `target="_blank"` حذف شد؛ لینک‌های لنگر (`#...` یا آدرس همان صفحه دارای هش) صفحه والد را به‌صورت نرم به بخش هدف اسکرول می‌کنند؛ لینک‌های عادی با مجوز `allow-top-navigation-by-user-activation` در همان پنجره مرورگر باز می‌شوند.
- **سازگاری با افزونه‌های سئو (Yoast و Rank Math):** هوک اختصاصی برای استخراج متن شورت‌کد در زمان آنالیز سئو اضافه شده تا تعداد کلمات نوشته‌ها به‌درستی ارزیابی شود. (توجه: برای مقالات متنی سئومحور، حالت عادی پیشنهاد می‌شود نه iframe).
- **اجرای PHP:** به‌صورت پیش‌فرض غیرفعال است. فعال‌سازی نیازمند تنظیم `CHS_DISABLE_PHP` در wp-config.php و ذخیره مجدد قطعه برای امضاست.
- **جایگزینی محتوا:** دیگر به‌صورت پیش‌فرض رابط خرید ووکامرس را مخفی نمی‌کند.

## ساختار مخزن

```text
custom-html-snippets/   کد قابل نصب افزونه
packages/              بسته آماده نصب نسخه ۳.۰.۳
tests/                 آزمون‌های شبیه‌سازی‌شده وردپرس و بازتولید باگ‌ها
docs/                  گزارش‌ها و راهنماها (شامل گزارش‌های تاریخی)
docs/ci/               نمونه غیرفعال GitHub Actions برای بررسی و ساخت بسته
```

## تست و ساخت

```bash
php tests/run-tests.php
php tests/integration.php
php tests/regression.php
php tests/compatibility.php
find custom-html-snippets -name '*.php' -exec php -l {} \;
for file in custom-html-snippets/assets/js/*.js; do node --check "$file"; done
zip -qr packages/custom-html-snippets-3.0.3.zip custom-html-snippets
```

## اطلاعات حساس

توکن‌ها، گذرواژه‌ها و فایل‌های محیطی را در مخزن یا Issue قرار ندهید. اعتبارنامه‌ای که در گفتگو یا مخزن افشا شده باید در GitHub لغو شود.

## فعال‌سازی GitHub Actions

به‌دلیل نبود مجوز workflow در اعتبارنامه ارسال، فایل نمونه در `docs/ci/github-actions.yml.example` نگهداری شده و گردش‌کار فعال نیست. با حساب دارای دسترسی مناسب، آن را به `.github/workflows/ci.yml` منتقل و commit کنید.
